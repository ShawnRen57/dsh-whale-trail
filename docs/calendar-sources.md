# 2026 年节日识别与来源

当前版本内置24个2026年节日日期，以档案固定时区（默认 `Asia/Shanghai`）中的自然日匹配。识别文化节日当天，不识别调休或整个假期。后续年份通过年度日历和物料更新支持，不复用2026农历对应公历日期。

- 中国农历节日、清明和冬至：以[香港天文台2026公历与农历日期对照表](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2026.pdf)核对。腊八为1月26日、除夕2月16日、春节2月17日、元宵3月3日、清明4月5日、端午6月19日、七夕8月19日、中元8月27日、中秋9月25日、重阳10月18日、冬至12月22日。
- 国际妇女节3月8日、世界地球日4月22日、世界海洋日6月8日：参照[联合国纪念日目录](https://www.un.org/en/observances/list-days-weeks)。
- 世界读书日4月23日：参照[联合国教科文组织](https://www.unesco.org/en/days/world-book-and-copyright)。
- 美国感恩节为11月第四个星期四，2026年11月26日：参照[美国联邦人事管理局年度假日日历](https://www.opm.gov/policy-data-oversight/pay-leave/federal-holidays/)。仅代表美国日期，不混用加拿大感恩节。
- 固定文化日期：元旦1月1日、情人节2月14日、劳动节5月1日、儿童节6月1日（中国，非联合国11月20日世界儿童日）、国庆10月1日（中国）、程序员节10月24日（本项目采用的中国社区习惯，非年第256日）、万圣节前夜10月31日（非11月1日诸圣节）、圣诞节12月25日。

精确数据在 [`assets/calendar-2026.json`](../assets/calendar-2026.json)，名称明确地区或习俗边界。节日徽章需要真实有效使用记录，安装插件、打开弹窗或领取操作不会触发。界面与备份迁移仍由本地事实推导授予日期。
