# Whale Trail · 鲸迹

**让每一次探索，都留下一枚值得收藏的徽章。**

Whale Trail for DeepSeek Harness 是一款小鲸鱼主题的本地成就插件。正常使用 Harness，就能自动点亮徽章、推进航海章节，解锁自己的 ASCII 水族馆，再把五枚珍藏做成可以带走的航海名片。无需打卡、领取或手动确认完成。

*Whale Trail is a local-first achievement collection, ASCII aquarium and shareable voyage card for DeepSeek Harness.*

> **非官方社区项目，由社区成员独立开发与维护，未获 DeepSeek 官方背书。** 当前版本 **1.0.0**。本版已核对 Harness **0.2.1-rc.2 / 0.2.1-rc.3 发行 SDK 契约**，并在 macOS **0.2.1-rc.3** 完成安装与界面验证；不以单一宿主版本号阻止安装，具体兼容范围见[兼容性](#兼容性)。

## 从「我的徽章」出发

点击 Harness 左下角 **用户信息 → 我的徽章**，在四个标签页中查看成就、航海收藏册、布置水族馆和制作名片。

- **自动记录成长**：徽章数、累计使用天数、最长连续、当前连续、Token 与完整对话轮次，一眼看见自己的航迹。
- **收藏自然解锁**：满足章节的累计天数与完整对话条件，自动获得装饰，不消耗 Token，也不需要领取。
- **外观由你决定**：页面水族馆默认关闭。选好已解锁装饰、密度、速度与颜色后保存，才会出现在 Harness 中。
- **把航程带走**：自选五枚已获得徽章，加上签名，导出高清 PNG 或能离线游动的 HTML 名片。
- **本地保存**：不新增模型调用、不上传聊天内容；备份同时带走成就记录与外观偏好。

### 新增的 8 枚探索航迹

| 徽章 | 自动获得条件 |
| --- | --- |
| 初试罗盘 / 三向探航 / 八方共鸣 | 在正常完成的顶层人类对话中，累计成功使用 1 / 3 / 8 种不同工具 |
| 三港相逢 / 十港航迹 | 在 3 / 10 个不同会话中，完成由你发起的正常对话 |
| 三日续航 / 七日重访 | 在同一个会话的 3 / 7 个不同自然日，完成正常对话；不要求连续 |
| 轻装再航 | 成功完成一次上下文压缩后，再次由你发起并完成正常对话 |

工具调用必须有可匹配的成功结果；不计鲸迹自身工具、失败结果、子代理、继承记录或后台自动续跑。缺少可靠证据时不猜测授予。

## 把水族馆留在 Harness 里

打开「水族馆」，选择已解锁装饰，调整**生物密度、游动速度、海洋墨色**，勾选「在 Harness 页面显示水族馆」，点击「保存水族馆」。偏好会在重新打开界面和重启后保留。

- **新对话**：在整块留白区域游动，避开前景标题和输入区域。
- **已有对话**：收拢到输入框本体的底部，以渐变轻轻浮现，不延伸到聊天正文。
- **安静工作**：装饰不接收点击、不抢焦点；页面隐藏时暂停，支持「静水模式」，并尊重系统减少动态设置。

锁定装饰不能配置；更换外观不会增加成就进度。宿主缺少所需布局锚点时，页面背景会隐藏，其他可用功能继续工作。

## 五枚珍藏，一张航海名片

在「航海名片」中，自选 **恰好 5 枚不同的已获得徽章**，写下最多 120 字符的签名。名片同时展示获得徽章数、累计使用天数与中文单位的 Token 数字，例如「100 万」「1 亿」。尚不足五枚徽章时，可以继续收藏，达到五枚后再生成名片。

名片沿用你保存的水族馆装饰与外观，并使用官方原始 **Powered by dsh** 品牌图。该图用于说明运行平台，**不代表 DeepSeek 对鲸迹的官方认证、背书或赞助**。

- **导出 PNG**：生成 1200×800 静态高清图片，保存动画中的一个瞬间，适合发送和贴进文档。
- **导出动态 HTML**：徽章图片、名片内容与动画都包含在单个文件中，用浏览器离线打开，水族馆仍可游动；减少动态设置同样生效。
- **分享高清名片**：浏览器支持文件分享时唤起系统分享；不支持时下载 PNG。导出和分享前会保存当前名片设置，不会自动上传或发布。

![航海名片：五枚精选徽章、个人签名、中文统计与动态水族馆](docs/images/voyage-card.png?v=1.0.0)

## 安装与升级

发布包已预构建，无需自行编译，也不需要额外配置模型或 API Key。

1. 从 [v1.0.0 Release](https://github.com/ShawnRen57/dsh-whale-trail/releases/tag/v1.0.0) 下载 `dsh-whale-trail-1.0.0.tgz`。
2. 在终端执行以下命令，将文件路径替换为实际下载位置：

```sh
dsh plugin --profile desktop add 'file:/绝对路径/dsh-whale-trail-1.0.0.tgz' --ignore-scripts
```

macOS 上如果没有全局 `dsh` 命令，可调用应用自带 CLI：

```sh
'/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh' plugin --profile desktop add 'file:/绝对路径/dsh-whale-trail-1.0.0.tgz' --ignore-scripts
```

3. 重启 Harness，打开左下角 **用户信息 → 我的徽章**。

升级前建议先导出 `.dshbadge`。安装新版并重启后，真实使用记录保留，章节和新增徽章由证据自动计算。旧版 10K / 100K Token 徽章仍不展示或计入获得数量，相关使用事实继续保留。

若需禁用，可在 Harness 插件页操作；卸载可执行 `dsh plugin --profile desktop remove dsh-whale-trail --ignore-scripts`，本地成就账本仍保留。

### 兼容性

v1.0.0 移除了 `engines.dsh` 单版本限制，宿主协议 peer 不再精确锁定某一个发行版；实际接入按能力判断。

已核对 **0.2.1-rc.2 与 0.2.1-rc.3 发行 SDK** 中的事件形态、账户菜单与页面布局契约，并提供相关自动测试。在 macOS **0.2.1-rc.3** 实际验证了安装、历史统计、四个功能页、外观保存及名片导出。这不等于承诺所有宿主版本、系统和界面都已实机验证。未来宿主改变接口时，可选页面背景或菜单扩展可能隐藏，需要更新插件；无法使用的能力不会通过猜测接入。详细边界见[开发说明](docs/DEVELOPMENT.md#宿主兼容与界面接入)。

## 怎么统计

**自动统计，首次安装时同步可读取的历史。** 只采用能够核实的事件，重复扫描或重复导入不会叠加进度。

- **使用天数**：顶层人类有效输入与实际回复或成功工具结果配对，按固定时区的输入日期累计；一天多次使用只计一天。默认时区为 `Asia/Shanghai`。
- **连续使用**：记录最长连续和当前连续；当前连续允许从昨天接续到今天。
- **Token**：累计 Harness 正式记录的模型用量，不估算缺失记录，也不把 Token Meter 压力当作实际消耗。
- **完整对话**：你发起一次有效输入，Agent 给出可见文本回复，且对应回合正常完成，计 1 轮。多条排队输入合并到同一回合时只计 1 轮；失败、中止、重试和后台自动续跑不单独计轮。
- **探索与章节**：从可归因的完整对话和成功证据推导，打开页面、修改偏好、导入外观都不能直接授予。

归档会话、手动确认和主动领取不参与计数。更详细的事件规则见[开发与实现说明](docs/DEVELOPMENT.md#事件与计数)。

## 备份与迁移

在弹窗底部点击 **导出备份**，带走生成的 **`.dshbadge` 文件**。换设备后安装插件，保持相同档案与时区，点击 **导入备份**；先预览新增、重复和补全记录，再确认合并。

v1.0.0 导出 **schema 4** 备份，包含最小成就事实、规则信息、外观偏好、精选五枚徽章与签名，并兼容导入 schema 1 / 2 / 3 的旧备份。

- 旧备份没有外观配置时，不会清空本机偏好。
- 导入 schema 4 时，本机尚未保存偏好才带入备份外观；已有本机偏好会保留。
- 备份中的装饰和精选徽章会按实际解锁结果检查，外观配置不能解锁奖励。
- 损坏文件或档案、时区、规则冲突会拒绝合并，避免部分写入。

账本本地保存；不保存提示词、回复正文、工具参数、附件、API 密钥或登录凭据。签名是你主动保存的展示内容，会包含在备份与导出的名片中。备份为明文元数据文件，校验和不等于加密。当前提供手动迁移，不提供自动云同步；请使用 `.dshbadge`，不要直接同步运行中的 SQLite 文件。
